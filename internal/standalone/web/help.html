SALCARA REMOTE

把电脑上的进度带到手机

未检查

本站只负责设备配对与消息转发。模型由你的电脑工具调用；连接不需要提交模型 API Key，扫码绑定后直接使用，不设用户审批。

连接步骤

  1. 在电脑端填写本站地址，选择 Agent 和需要使用的 API，再检查远程通道。
  2. 电脑生成临时二维码；用 Salcara 手机端扫码绑定，只能连接自己的设备。
  3. 手机选择电脑和原会话，按需查看进度或发送任务。网络恢复后先查询原任务状态，不要重复提交。

换中转站要重新配对。此页面不展示其他人的设备、会话或管理统计。

公开通道检查

仅检查本站 Hub，不能确认你的电脑已在线或 Codex 桌面已授权。

使用边界

当前不是端到端加密，本站可读取转发内容，请只连接信任的站点。Codex 原桌面续聊需要明确安装和限时授权；Claude Desktop 普通聊天远控尚未完成。CLI 与原桌面会话是不同路径。

设备、配对和封禁保存于独立 Hub 数据卷。运行中的会话事件只是限量缓存，不是永久云端聊天备份。服务器省资源模式会缩短暂存历史；完整历史仍需要从电脑端读取。

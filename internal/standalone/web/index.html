手机直连

无需 Sub2API API Key

电脑端 Salcara Bridge 和手机端 Salcara 都填写同一个 Hub 地址。Hub 只转发设备消息；模型 API 凭证留在电脑或由电脑上的 Agent 账号管理。

正在读取 Hub 地址
  1. 新电脑首次连接时，进入“设备”页生成一次性设备登记码，并在 Bridge 的“手机远程”高级选项中填写。
  2. 电脑连接成功并在线后，在 Bridge“手机远程”生成绑定二维码。
  3. 手机进入“编程”，输入上方 Hub 地址并扫描电脑二维码。手机二维码由已登记电脑生成，不由 Hub 管理页代发。

公网连接必须使用 HTTPS。登记码用于首次登记电脑；配对二维码用于绑定手机，两者不是模型 API 凭证。

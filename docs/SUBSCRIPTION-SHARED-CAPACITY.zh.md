# 订阅来源共享并发额度

一份机场订阅中的多个节点可能共享供应商资源。现在可为同一订阅来源设置请求和长连接的总额度，防止单节点限额叠加后超过管理员预期。这个功能限制并发数量，不测速、不计算带宽套餐，也不承诺通过增加节点数得到更多带宽。

## 管理流程

在“线路与代理池 → 订阅”找到来源，点击“共享额度”。分别填写 1–4096 的请求额度与长连接额度，点击“检查并准备应用”。此时配置尚未生效；到“配置发布”查看回源检查结果，通过后开始两分钟试用，最后确认或回滚。取消勾选会移除该来源的额外限额，全池和各节点限额仍然生效。

首次没有设置来源额度时，保留原行为。每个请求的实际容量受到三个条件共同约束：全池空位、来源空位、节点空位。选择与预留在同一把锁内完成，不能在并发请求之间超卖名额。请求与 SSE 长连接分别计数，探测任务继续使用独立的全局探测预算。

来源卡片显示总占用；“当前负载 → 订阅共享容量与旧连接”也展示已移除节点仍在占用的连接。运行观测会解释“共享请求额度已满”“共享长连接额度已满”等原因。

## 连接和更新语义

- 降低额度不会踢掉已有连接；已有占用高于新上限时，新请求等待有界队列或按既有规则拒绝。
- 订阅刷新、密码轮换、节点换代、移除及回滚不会把仍在途的来源占用清零。每条请求保留取得名额时的计数归属，结束时精确释放一次。
- 负载均衡可选择另一个有容量的合格来源。手动 / 主备 / 延迟优选继续沿用既有选定线路和排队语义，不因来源容量满自动改变这些模式的含义。
- 来源尚被当前配置、试用前配置或保留历史中的额度引用时，不能删除。先取消额度，并等历史引用按现有版本保留策略退出；不会为了删除来源破坏回滚依赖。即使历史已淘汰，仍有在途请求或长连接的来源也必须等连接排空后才能删除，防止通过反复删除和重建累积无界退役分组。
- 额度随配置持久化，重启后恢复；进程重启会终止现有连接，运行计数重新开始。没有当前节点、没有额度且旧连接全部结束的来源计数会回收，再出现时重新计数；历史仍保护来源记录和回滚配置，但不保留空闲运行计数。当前共享占用是即时状态，未新增来源组的历史趋势。

第一版按稳定的 `SourceID` 分组，不依赖名称、ASN 或地理数据库。同一供应商的两份订阅不会自动合并；手工 HTTP/SOCKS 节点仍由全池与节点限额约束。跨来源合并、跨 Edge 配额、按用户公平性和自适应容量仍属后续能力。

## 接口

代理池状态新增：

- `source_limits: [{source_id, max_requests, max_streams}]`：当前显式配置。
- `source_groups: [{source_id, limited, max_requests, max_streams, node_ids, runtime, request_available, stream_available, retired}]`：当前来源占用及可用容量；未设来源限额时 `limited=false`，两个上限为 0，不表示禁止连接。

通过现有 `/v1/releases/prepare` 提交 `action:"policy"`，在 `payload` 中带 `source_limits`，并带当前配置 `expected_revision`。省略数组保留现有配置，空数组清除全部来源限额，提供数组则整体替换；最多 32 个不同来源，ID 为稳定的 32 位小写十六进制。Hub 转发同时要求当前 `expected_controller_id`。

直接向旧 `/v1/policy` 提交 `source_limits` 会返回 `source_limits_require_release`，避免绕过预检和试用。来源额度与普通策略一起进入历史快照、试用恢复和独立回滚。

## 验证范围

`internal/edgepool/source_capacity_test.go` 覆盖真实 TLS 回源及代理下的三层并发准入、普通请求与长连接隔离、降限排队与取消、凭据换代/节点删除/来源移动后的原计数归属、重复结束的精确释放、订阅刷新继承额度、来源删除引用、持久化失败保留旧配置。

`TestSourceCapacityReleaseRollbackPersistenceAndValidation` 使用真实 TLS 回源进行预检，验证准备、试运行、手工回滚时在途请求和来源计数对象保持不变，再验证确认和重启持久化。`TestSourceCapacityDeadlineAndRestartRollback` 覆盖试运行到期与未确认重启自动回滚。`TestSourceCapacityRetiredLeaseBlocksSourceRemovalAfterHistoryExpires` 确保历史淘汰仍不能删除在用的退役来源。

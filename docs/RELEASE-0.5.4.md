# Salcara Hub 0.5.4

本版配套 Salcara Android **1.8.4** 和 Salcara Desktop / Bridge **1.6.6**。正式发行与下载以 GitHub Releases 为准。

## 连接与服务发现

- 改进手机和电脑的服务发现与连接提示。普通 API 地址可在受支持的部署路径中发现 Hub；设备登记、手机配对、来源权限和服务不可用分别返回明确状态。
- 匿名发现只展示全站公开策略；电脑的实际授权单独核验，避免过期凭据把可用服务误判为故障。
- 同一 Hub 的多个访问地址经过签名与身份校验后才能切换。重启保留实例身份；重新部署为不同实例时，旧设备凭证不会直接交给新实例。

首次发现不支持猜测任意未知插件路径，特殊部署仍需填写准确入口。入口别名不会扩大 API 或账号的使用权限。

## 手机新会话与项目

- 配合新版手机和 Bridge，可浏览已配对电脑的本地磁盘，选择位置并创建新项目文件夹。
- 支持选择“不关联文件夹”开始新会话。已有项目内的新会话继续使用该项目的精确路径。
- 目录结果只返回当前配对目标，不保存为持久会话内容。配对撤销、目标改变或权限不足时拒绝操作；创建结果不确定时先刷新确认，不自动重复创建。
- 原有已授权项目列表继续兼容。浏览目录不会授权整个磁盘，也不会自动发起模型任务；网络盘不在本次支持范围。

目录浏览需 Hub 与 Bridge 都声明支持；无文件夹会话还要求 Hub 的持久回执存储可用。模型来源授权和禁止执行策略继续生效。

## 配套版本与升级

公开首页和服务状态页统一显示 Android **1.8.4** / Bridge **1.6.6**。配套清单嵌入 Hub，更新手机或电脑后也需部署对应 Hub 才会更新线上页面。

本版保持现有最低兼容门槛，不新增强制更新。使用上述新功能应更新到本次配套客户端；旧客户端不会因页面版本变化获得新能力。

确认正式 Release、固定版本镜像及签名资产可用后，按 [Docker 部署说明](STANDALONE-DOCKER.zh.md) 升级。先备份原配置和完整持久数据，保留现有 Compose 项目、卷和 HTTPS 地址。已有 0.5.x 安装不重新初始化、不删除数据卷；0.4.0 的认证迁移仍按部署指南处理。

管理员账号、设备配对与既有数据继续保留。网页更新只替换 Hub 子程序；镜像和启动器升级采用完整 Docker 镜像。程序回退不等于数据回滚。发布沿用原 Ed25519 身份，不覆盖旧版本资产，详见 [发布与更新维护](STANDALONE-RELEASE.zh.md)。

构建、自动回归与产物校验不能替代实体手机全链路或 arm64 实机验收；各项实际结果以本次发布记录为准。

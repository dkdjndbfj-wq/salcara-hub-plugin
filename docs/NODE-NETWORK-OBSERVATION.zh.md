# 节点网络归属观察

管理员可在“线路与代理池 → 网络归属”安装本地 DB-IP Lite 国家与 ASN 数据库，观察节点**服务器地址**的归属。这个功能不测量代理出口，也不定位用户；不会把用户 IP 发送给第三方查询服务。地区、网络组织和实际延迟是不同证据，不能用地理距离推断加速收益。

## 安装和日常使用

首次点击“安装并开启”会从 `download.db-ip.com` 下载当月国家及 ASN 的 `.mmdb.gz`，在本地完整校验、私有目录落盘后原子切换。镜像不捆绑数据库，不接受任意下载地址或自定义数据库脚本。每份下载上限 32 MiB，解压上限 64 MiB；总安装最多 4 分钟。2026-11 官方两份数据库实测解压总大小约 17.3 MiB，运行时还需要解压、校验和更新的临时内存。

可以分别控制自动观察和月度数据库更新：

| 行为 | 默认值 / 边界 |
| --- | --- |
| 自动观察 | 安装后开启，每轮完成后 6 小时再观察；也可手动观察全池 |
| 观察有效期 | 最多 24 小时，且不得超过数据库构建后 45 天 |
| DNS 解析 | 单节点 5 秒、整轮 60 秒、最多 64 个地址，与探测任务共享 4 个并发槽位 |
| 自动更新 | 安装后开启，检查月度版本；失败 1 小时后重试，待重试状态跨重启保存 |
| 观察任务中断 | 保留上一轮结果，10 分钟后再试，不计为节点健康失败 |
| 并发任务 | 安装、观察、设置修改互斥；版本冲突拒绝旧表单提交 |

安装失败保留原数据库；成功更新也保留仍有效的旧观察，直到新观察完成或原有效期到达，避免严格地区策略在换代间隙断路。不会延长旧观察的有效期。手动关闭观察后，更新数据库不会重新打开它；自动更新开关独立生效。

原生 HTTP/SOCKS 节点查询其服务器主机地址；Mihomo 节点查询订阅保存的原始服务器地址，不查询本机转发监听端口。私网、本地、直连、解析失败与多地址归属冲突分别显示，不猜一个国家。节点删除或服务器身份改变后旧结果不再匹配。国家为 ISO 两位代码；ASN 表示自治网络编号，组织名称不保证等于零售 ISP。

## 用于调度

“自动检测与切换阈值”中可选择“未手动标注时，使用有效的服务器地址国家代码参与地区选路”。默认关闭，开启前可以只观察数据。

1. 手工地区标签优先。
2. 未手工标注且明确开启 `use_observed_region` 时，使用新鲜、无歧义的国家代码，例如 `HK`、`SG`。
3. 过期、缺失或冲突的数据按未知处理；“仅使用这些地区”不会偷偷绕过限制。
4. 地区过滤后仍执行健康、容量和实际延迟策略。手动固定模式保持原来的语义。

如果当前严格地区规则依赖观察数据，直接关闭观察会被拒绝；先通过既有安全发布流程取消 `use_observed_region` 或改变地区模式，再暂停观察。该保护避免管理员在附加功能面板中无意切断所有线路。观察本身仍会过期，故严格模式应预留已验证的人工标注线路或合理的恢复方案。

共享 ASN 列表用于发现可能相关的网络故障，不自动把它解释成共享供应商带宽。管理员可另外配置 [订阅来源共享额度](SUBSCRIPTION-SHARED-CAPACITY.zh.md)，与全池及节点限额共同生效；分组依据稳定订阅身份，不依据 ASN。跨来源合并、自适应容量、跨 Edge 配额尚未实现。

## 接口与数据

Edge 控制接口位于 `/v1/geodata/`：`state` 使用 GET；`install`、`observe`、`configure` 使用 POST，均要求独立管理认证。写操作携带 `expected_revision`；`configure` 另带 `enabled`、`auto_update`。异步操作返回 202 和 `run` 进度，不能把 202 当作完成。

Hub 通过现有管理会话与 CSRF 保护的 `/salcara-hub/_admin/v1/network/geodata/*` 转发，仅投影公开类型；写操作携带 `expected_controller_id`，防止切换管理对象后操作旧服务器。geodata revision 独立于代理池配置 revision。

`Node.network` 提供 `status/country/asn/organization/addresses/source/method/observed_at/expires_at`；`method` 固定为 `server_address`。`effective_region` 是当前策略实际使用的标签。`GeoState` 提供数据库月份、构建时间、安装时间、更新计划、`update_pending`、运行进度和 ASN 分组，不返回源订阅或代理认证数据。

数据位于 Edge 私有目录 `geodata/`，包括原子状态文件和校验过的代际数据库。损坏的地理状态不会阻止 Edge 启动；本功能降级并报告错误。现有代理与订阅凭据存储方式不变。

数据来源：**IP Geolocation by [DB-IP](https://db-ip.com)**，采用 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。Lite 数据精度有限；MaxMind 格式解析库的 ISC 许可见 `licenses/MAXMINDDB-LICENSE`。

## 已验证范围

单元和 race 回归覆盖混合 / 私网地址、DNS 失败、证据过期与身份替换、人工标签优先、明确选路开关、共享探测预算、取消关闭、安装失败保旧、数据库换代保留观察、严格策略关闭保护、持久失败重试和配置发布恢复。显式联网测试下载并校验了 2026-11 官方两份数据库，验证真实 ASN 查询。

实际本地 Hub + Edge + Edge 浏览器完成安装、观察与管理操作，检查 1440 / 390 / 320 像素明暗主题。测试环境使用独立私有状态和本地测试 TLS；未部署生产服务，未验证某家机场的线路收益。

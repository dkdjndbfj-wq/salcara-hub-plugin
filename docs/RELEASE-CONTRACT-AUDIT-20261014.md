# 发布产物一致性专项复核（2026-10-14）

范围仅为手机发布说明校验与 Hub 发布工作流、辅助脚本、测试及维护文档。不修改手机或桌面 UI，不调用付费模型、不使用真实凭证，不触发 GitHub 工作流、签名、上传或生产部署。

## 已修复

- 手机：构建前必须找到当前精确版本的一份有效说明，兼容 `RELEASE-v版本.md` 与 `RELEASE-版本.md`；缺失、空白、符号链接或两份同时存在均停止。发布只消费已验证文件，不自动生成说明替代它。
- Hub：只构建一份含双架构、provenance 和 SBOM 的 OCI 归档；导入、容器 smoke、二进制导出及发布绑定该归档。发布任务按 artifact ID 下载，不重新构建。
- OCI 校验验证每个引用 blob 的摘要、大小、平台、版本、非 root 配置及证明 subject；receipt 绑定源码 SHA、归档和镜像图。
- 真实 BuildKit 实验发现，未设置镜像名称时 subject 可能为空。工作流现显式设置正式 tag，但构建仍为 `push: false`；空 subject 仍拒绝，未削弱校验。
- 真实 Docker 实验发现，containerd 存储的 `inspect.Id` 可为 manifest digest。现从捕获的不可变镜像 ID 执行 `docker image save`，核对实际 config 原始字节，而不是误把 manifest 当 config；导出二进制也使用该 ID。
- 同版本发布跨 ref 排队；只接受认证且结构明确的缺失响应。已有版本、鉴权或网络异常全部拒绝；上传结果不确定时不自动重试覆盖，上传后再次核对实际 index 字节和 digest。
- 工具 smoke 失败清理登记实际导入 ID；部分导入、单个清理失败不会阻止其余本任务资源的清理，不删除改变身份或不属于本任务的镜像，也不掩盖原始验证错误。

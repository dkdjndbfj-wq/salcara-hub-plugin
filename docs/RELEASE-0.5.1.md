# Salcara Hub 0.5.1

独立 Docker Hub 修复更新，产品、发布者公钥、管理密钥和设备配对协议保持兼容。建议配合 Salcara Desktop 1.6.2 和手机 1.8.1 使用。

- 修复真实扫码配对后重启时读取持久化记录失败。
- 收紧活动手机绑定、重绑代际及二维码身份校验。
- 改善长轮询事件到达、解绑唤醒和授权复核。
- 提供事件上传批次幂等校验，配合新版桌面端避免回包丢失后的重复进度。
- 首次部署脚本统一按当前版本校验 Release 和健康状态，避免版本升级后错误拒绝安装。

0.5.x 用户可通过管理页检查更新；网页更新只替换签名验证的 Hub 子程序。完整 Docker 镜像升级须保持原项目名和持久卷，拉取 `ghcr.io/dkdjndbfj-wq/salcara-hub-standalone:0.5.1` 后重建 Hub 容器。不要重新初始化管理密钥或删除数据卷。0.4.x 仍需先按部署教程完成认证迁移。

Hub 不保存 API Key，也不是永久消息存储。长离线或超缓存后，手机须从电脑重新读取会话。不会自动更新 Sub2API，不向 Hub 开放 Docker socket。

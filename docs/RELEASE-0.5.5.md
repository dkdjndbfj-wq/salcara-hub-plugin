# Salcara Hub 0.5.5

本版配套 Salcara Android **1.8.5（versionCode 26）** 和 Salcara Desktop / Bridge **1.6.7**。实际发行、镜像及下载资产以正式 GitHub Release 和发布校验记录为准；本文不是线上服务器已升级的声明。

## 可信登记与原身份恢复

- 支持由明确受信的 API 登记服务核实用户资格、向 Hub 提交短效签名授权后登记电脑。模型 API Key 不交给 Hub；未部署可信登记服务的站点仍保留管理员登记码流程，不因模型列表可用就自动授权。
- 已登记电脑优先使用原设备身份恢复，不因 API Key 变化或响应丢失重复登记、生成新电脑。
- 地址变化时，手机和电脑先核验原 Hub 身份、签名入口清单及新鲜证明，再发送已有凭据；不自动信任同 URL 下的替换实例。所有旧入口都不可达时，仍需管理员提供新地址并完成同身份核验。

## Bot 绑定、恢复与撤销

- 保留原六字段绑定 JSON；新手机绑定协议支持先绑定空组，再等待电脑加入。绑定回包丢失时恢复同一次请求，不占用第二次绑定，也不清掉已有任务。
- 区分撤销邀请、手机自撤销和管理员原组重置。撤销邀请仅停止新增绑定；手机自撤销同时使旧邀请失效。管理员可在原组确认重置并签发新邀请，保留电脑身份和历史，不需另建组。
- 撤销与重置写入持久意图并在启动时恢复；存储失败明确显示待重试，不假报完成。旧手机权限及时退出事件、图片、回执、任务和通知路径，长连接及等待中的请求重新检查权限。
- 管理页刷新或重新登录后可恢复结果不确定的重置请求；本地只保存非秘密请求元数据，不保存邀请或手机凭据。新增默认收起的公开身份核对区，供旧绑定显式恢复时核对实例 ID 和公钥。

## 通知与消息

- Bot 通知使用独立的组、手机代次和电脑授权，不借用普通扫码配对权限。换手机、撤销、封禁或移出组后，等待发送的旧通知不能沿用新权限。
- 任务失败、审批和提问分别保留有效身份与状态；同轮普通完成和回复合并，过期或已解决请求在发送前再次核对。
- 通知状态与待发记录随消息在同一持久事务中保存，重启后恢复前再次鉴权。Android 保留分任务信息；iOS 普通结果短暂合并摘要，紧急请求不等待该窗口。通知不携带正文或授权秘密，也不代表审批/执行许可。

## 配套版本与升级

公开首页和服务状态页共用清单，显示 Android **1.8.5** / Bridge **1.6.7**。该清单嵌入 Hub 构建；必须实际更新运行中的 Hub，线上页面才会同步。发布 Release、镜像或签名清单不会自动重启用户服务器。

本版不提高最低兼容门槛、不新增强制更新，沿用既有 Ed25519 发布身份，不覆盖旧版本资产和旧协议更新源。新功能以本次配套客户端声明的能力为准，不表示所有旧版本都具备新能力。

确认正式资产可用后，按 [Docker 部署说明](STANDALONE-DOCKER.zh.md) 升级。先停止准确的 Hub 项目并一致性备份完整 DataDir 与卷外配置，保留原项目、卷、身份和 HTTPS 地址；已有 0.5.x 不重新初始化，不执行 `down -v`。

完整备份包含 `bot-phone-intents.json`、Bot 主状态、设备/撤销记录、身份与签名材料、消息/通知数据库和更新状态。存在待完成撤销/重置时，不得删除意图日志、直接降级到不理解该日志的旧版本，或用旧备份恢复已撤销的权限。程序回退不等于数据回滚，须先核对兼容性与最新撤销事实。网页更新仅替换 Hub 子程序，镜像与启动器仍按完整 Docker 升级流程维护。

## 验证范围

本版功能源码已通过全仓回归、并发检查和管理界面逻辑测试。固定 Hub / Mobile / Bridge 源码的两组本地 TLS 联调覆盖空组绑定、丢回包恢复、两台电脑任务与事件往返、保留 DataDir 后的新入口认证读取，以及撤销和重启后的旧凭据拒绝。

四类 Agent 使用实际 Bridge 调度器与可计数的合成执行器；Mobile 使用真实产品模块和隔离内存存储，不是 Android 真机或真实 Agent 服务。迁址用两个合成逻辑地址映射本地 TLS，仅证明迁址后的认证读取，不是公网 DNS/IP 迁移或迁址后 Agent 执行。旧 URL 邀请的地址校验拒绝与撤销后的凭据拒绝分别记录，不混作同一证据。

最终发布构建、双架构资产、签名、镜像和 HTTPS 下载须按 [发布维护流程](STANDALONE-RELEASE.zh.md) 单独验收；源码回归不代替这些产物检查。安装版实际渲染、Android/arm64 真机、公网代理链路和真实 FCM/APNs 送达仍需目标环境验证，不把模拟通知或安装器路由检查当成线上端到端验收。

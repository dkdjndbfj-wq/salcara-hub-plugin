# 三端产品收尾记录（2026-11-08）

本记录区分源码实现、本机验证和真实发布验收，避免把旧正式安装包与工作区里的新能力混为一谈。此次没有向用户 VPS 部署、发布正式安装包或改变更新通道。

当前按 [GitHub 发布与可用性说明](GITHUB-RELEASE-READINESS-20261108.zh.md) 收尾，以部署、连接和核心远程操作可用为目标。商业防破解、容量认证和完整生产运维演练不作为源码／测试版本发布前提。此前核对补修了旧 v1 Bot 绕过全站暂停的兼容边界，该修复通过相关范围回归。

## 已落实的产品改动

### Hub

- 运维中心沿用手机端的配色与圆角层级，包含服务健康、备份恢复和协作管理；桌面双列、窄屏单列。
- 主管理员、运维、只读、监控接口权限分开；独立随机密钥仅显示一次，持久化摘要，撤销已有会话。
- 管理写操作先保存审计意图；写盘失败则不执行。可按操作者、操作、结果、设备匿名标识查询并导出 NDJSON，执行结果未知保持未确认。
- 管理页前台每 30 秒检查健康；聚合监控接口与 Prometheus 告警规则支持服务离线、磁盘预留、存储容量和备份逾期。
- 完整数据目录离线加密备份、读回校验、恢复到新目录；检查 SQLite、解密密钥匹配、部署模式、管理记录及逐文件清单，保留更新程序的拥有者执行位。
- 存储设置草稿不会被刷新或迟到的保存响应覆盖；退出和页面关闭清空 Bot 绑定包及存储状态；Bot 撤销的失败和迟到响应有明确处理。
- 远程使用授权按全站统一控制本站 API、其他中转站 API、反代账号和受支持的本地官方账号；三份完整来源地址名单分别保存，关闭一类不影响另一类。
- StationPolicy v2 要求电脑声明 `station.guard.v2`，拒绝旧客户端静默忽略新类别；策略修改会撤销旧版本 grant，过期页面不能恢复已关闭来源。管理台分来源显示签名配置覆盖，配置就绪不等于上游账号已验证或服务已连通。
- v2 Bot 入口通过当前组与手机令牌代次绑定来源授权；正常取签名和实际发送、换手机后拒绝旧授权、跨组隔离及重启绑定稳定性均有回归验证。

操作步骤和限制见 [协作管理、审计、监控与备份恢复](OPERATIONS-AND-RECOVERY.zh.md)。外部告警需要实际部署采集器和接收渠道，不能把代码内的接口与规则描述为已发送告警。

全站授权的操作与部署步骤见 [远程使用授权](REMOTE-SOURCE-AUTHORIZATION.zh.md)。历史 v1 保留原共享名单语义，管理台首次保存迁移到 v2；分类授权是业务规则，不能当作对恶意修改客户端的硬件证明。

### 电脑端

- 手机远程页增加消息与恢复状态：本机保存是否正常、待同步数量、最近送达 Hub 时间，以及核对原会话的入口。
- 断线和恢复及时更新二维码与连接状态；迟到初始化/刷新不覆盖电脑名称、项目路径和登记码草稿。
- 已有恢复数据而本地加密密钥丢失时停止初始化，保留原数据，不生成替代密钥掩盖问题。
- 修复 Windows Direct TLS 对文件 owner 的多余重设导致配对失败；仍要求私有 DACL 和正确拥有者。
- 修复 Codex 配置应用/回滚对 Windows ACL 记账字段的误判；实际权限、主体、ACE 顺序、继承和保护位仍受校验。
- 电脑执行端严格解析 v2 来源分类，在模型发现、候选站点、账号选择和实际执行时应用同一来源规则，并返回可读的拒绝原因。

实现与相关回归位于 `salcara-desktop/remote/bridge`。

### 手机端

- Android 后台监听增加设备绑定的加密恢复检查点，保存于排除系统备份的应用私有目录；关闭通知、解绑、失效或到期时清理。
- 系统允许服务重启时恢复监听游标，不发送新的业务任务。任务观察与待命分别有 2 小时和 7 天租约；不承诺绕过系统强行停止、手机重启或厂商省电限制。
- 通知菜单区分用户开关与实际运行状态，异常时可前台重连并查看系统设置说明。
- 按用户要求删除更多弹框中重复的首页、切换 Agent、连接电脑、API 管理、下载等导航；保留必要通知设置，不新增返回按钮或设置页面。Android 系统返回先关闭弹框，再按原层级返回。
- 系统授权按功能触发；照片选择移除不必要的全库读取前置要求，拍照、麦克风和保存图片的永久拒绝提供可操作的设置入口。跳转失败有说明，返回后不自动重试；实时语音启动失败及时释放连接和音频资源。
- Android 媒体声明限定为照片，移除未使用的音频库、视频库和悬浮窗权限；保留相机、录音和旧系统保存图片所需权限。

恢复设计见手机仓库 `docs/maintainers/REMOTE-BACKGROUND-RECOVERY-20261107.md`。
权限行为与验收矩阵见手机仓库 `docs/maintainers/SYSTEM-PERMISSIONS-20261108.md`。

GitHub 源码／测试版本交付不要求先完成所有平台正式签名、商业容量测试或生产告警部署。发布正式安装包时仍沿用既有签名与更新身份；使用者按需部署 HTTPS、推送和监控。当前没有真实跨境链路提速数据，也没有本轮 iOS 构建证据。

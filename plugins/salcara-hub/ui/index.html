协议 v1

电脑填写本站地址并检查插件能力 → 电脑生成临时二维码 → 手机扫码绑定。无需本站用户账号或模型 API Key；手机只能控制自己配对的电脑。

绑定保存在本站，换中转站需要重新连接与扫码。关闭本插件会断开远程连接，不影响电脑本地使用和模型调用。

安全提示：当前并非端到端加密，本站服务器可读取转发的会话和控制请求；请只连接信任的站点，并使用 HTTPS。
